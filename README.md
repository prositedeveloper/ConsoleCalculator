# MetaCalculator — консольный калькулятор на Qt с метапрограммированием

# 3 Вариант
### Калькулятор с метапрограммированием. Использовать QMetaObject::invokeMethod() для вызова операций по имени строки

Демонстрация метаобъектной системы Qt: вызов слотов по имени строки
через `QMetaObject::invokeMethod()`.

## Возможности

- Арифметические операции: `add`, `sub`, `mul`, `div`, `pow`, `mod`, `sqrt`
- Динамический вызов слотов через метасистему Qt (без `if/else if` цепочек)
- Обработка ошибок (деление на ноль, отрицательный корень) через сигнал `errorOccurred`
- Демонстрация принципа "один сигнал → несколько слотов" (вывод + запись в файл)
- История операций в `history.txt`

## Сборка

```bash
qmake MetaCalculator.pro
make          # Linux/macOS
mingw32-make  # Windows (MinGW)
```

## 📚 Ответы на контрольные вопросы
```
1. Метаобъектная система Qt — надстройка над C++, дающая рефлексию: имена классов во время выполнения, вызов методов по строке, сигналы/слоты, свойства (Q_PROPERTY), динамические приведения типов.

2. Зачем Q_OBJECT — макрос, который MOC заменяет на метаинформацию: таблицу сигналов, слотов, свойств. Без него нет ни сигналов, ни invokeMethod(), и компоновка упадёт с undefined reference to vtable.

3. MOC — Meta-Object Compiler, препроцессор Qt. Читает .h с Q_OBJECT, генерирует moc_*.cpp с метаданными и реализациями сигналов.

4. QCoreApplication vs QApplication — первый для консольных приложений без GUI (не тянет QtWidgets), второй — для GUI (нужен для виджетов).

5. Сигнал vs слот — сигнал только объявляется, реализацию генерирует MOC; слот — обычный метод с реализацией. Сигнал нельзя вызвать напрямую (только emit), слот — можно.

6. Прямой вызов слота — работает как обычный вызов метода, сигнал не излучается. emit нужен только для сигналов.

7. Один сигнал → много слотов — да, через несколько connect. Один слот ← много сигналов — тоже да.

8. qFuzzyIsNull — корректное сравнение double с нулём с учётом погрешности. == 0.0 может дать false для 1e-300.

9. Типы соединений — AutoConnection (по умолчанию), DirectConnection (сразу), QueuedConnection (через очередь событий, для потоков), BlockingQueuedConnection (с блокировкой), UniqueConnection (защита от дублей).

10. Без app.exec() — цикл событий не запустится, GUI не отрисуется, таймеры и сеть не будут работать.

11. Слот из другого потока — можно, но нужен QueuedConnection (или BlockingQueuedConnection) и потокобезопасность данных.

12. Отключить соединение — QObject::disconnect(...).

13. invokeMethod() — динамический вызов метода по имени строки. Полезен для скриптов, плагинов, RPC.

14. Проверка, что сигнал излучён — в тестах QSignalSpy.
```
